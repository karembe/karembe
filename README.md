## Currently Building

### [Tally](https://github.com/karembe/Tally) — reliability-first systems engineering

> **Flagship project · early development**

I'm building **Tally** as a production-oriented engineering project around one deep problem: keeping a transaction system **correct, auditable, and recoverable when things fail**.

The core is being designed around idempotent and crash-safe transfers, an append-only hash-chained event log, reconciliation, and verifiable system invariants. Around it, the project grows into a full delivery and operations path with **Kubernetes, Helm, GitOps, CI/CD security gates, AWS infrastructure, Infrastructure as Code, runtime hardening, observability, alerts, and SLOs**.

`Java` · `Spring Boot` · `PostgreSQL` · `Kubernetes` · `Helm` · `Argo CD` · `GitLab CI/CD` · `AWS` · `Terraform` · `Prometheus` · `Grafana` · `OpenTelemetry`
