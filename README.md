## 🚧 What I'm Building Now

### [Tally](https://github.com/karembe/Tally)

> **My flagship systems project — currently in development.**

Tally starts with a reliability problem: **how do you keep a transaction system correct, auditable, and recoverable when things fail?** I'm using that core to build a production-style DevSecOps/SRE environment around crash-safe transfers, tamper-evident records, reconciliation, GitOps delivery, hardened Kubernetes workloads, cloud infrastructure, security gates, observability, alerts, and SLOs.

`Java` · `Spring Boot` · `PostgreSQL` · `Kubernetes` · `Helm` · `Argo CD` · `AWS` · `Terraform` · `Prometheus` · `Grafana` · `OpenTelemetry`

## 🧩 Featured Engineering Work

### [Agora](https://github.com/karembe/Agora) — secure AI agent platform
Self-hosted agent infrastructure with a Spring Boot gateway, Python agents, RBAC, capability-based authorization, human approval for sensitive actions, tamper-evident audit logging, and observability.

### [ENSET AI](https://github.com/karembe/ENSET-AI) — private RAG platform
Authenticated document chat with citations, streaming responses, Postgres metadata, S3-compatible object storage, vector retrieval, administration, and self-hosted deployment.

### [Faseeh](https://github.com/faseeh-app/Faseeh) — extensible desktop product
A collaborative local-first language-learning toolkit built with Electron, Vue, and TypeScript around a plugin architecture and interactive media workflows.

### [ML WAF](https://github.com/karembe/ML_Trained_Firewall_For_Web_Apps) — machine-learned application security
An inline reverse proxy that detects SQL injection and XSS in real HTTP traffic using LightGBM, with explainable decisions, live operator tooling, and reproducible testing.

### [E-Bank](https://github.com/karembe/E-Bank) — event-driven banking system
Java/Spring microservices with Kafka, service discovery, idempotent money operations, an outbox pattern, and ledger reconciliation.
